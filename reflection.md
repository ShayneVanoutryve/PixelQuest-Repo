# Wat is het verschil tussen Watch, Star en Fork?
- watch is dat je de repo "bekijkt" en je krijgt meldingen
# Waarom zijn Issues nuttig in een softwareproject?
- dan weet je wat je kan maken als je geen werk hebt
# Hoe helpen Labels en Milestones bij projectbeheer?
- dan kan je onder een categorie zoeken als er heel veel issues staan en door milestones weet je wat de nieuwste versie is met welke updates
# Waarom controleer je een Pull Request voor je die merge?

# Wat is het verschil tussen Raw, History en Blame?
- raw is de ruige code acher een preview 
- history is de geschiedenis binnen een repo
- blame is dat je kan zie wat heeft ge commit en gepushed heeft op de repo
